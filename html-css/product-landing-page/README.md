# Product Landing Page

Lernprojekt im Rahmen von freeCodeCamp.

## Inhalt

Statische HTML/CSS-Übung. Die Aufgabenstellung stammt aus dem freeCodeCamp-Curriculum.

## Starten

Öffne `index.html` in einem aktuellen Browser. Es ist kein Build-Schritt erforderlich.
