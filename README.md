# freeCodeCamp Projects

Sammlung meiner Lernprojekte und Übungen aus dem freeCodeCamp-Curriculum mit HTML, CSS und JavaScript.

## Zum Einstieg

- [Umfrageformular](html-css/survey-form/README.md): Formularstruktur und CSS-Gestaltung.
- [JavaScript-Dokumentationsseite](html-css/technical-documentation-page/README.md): Navigation, Codeblöcke und Layout mit Media Queries. Ein HTML/CSS-Projekt über JavaScript, keine JavaScript-Anwendung.
- [Spielkarten](html-css/page-of-playing-cards/README.md): Flexbox und CSS-Gestaltung.
- [Golf Score Translator](javascript/golf-score-translator/README.md): kleine JavaScript-Funktion, kein vollständiges Golfspiel.

## Lokal ansehen

Das Repository herunterladen und die jeweilige `index.html` öffnen. Es gibt keine Paketinstallation und keinen Build-Schritt. Die JavaScript-Übungen besitzen eine ergänzte Browservorschau. Formulare sind Demos ohne Versand oder Speicherung.

## Einordnung

Die Projekte entstanden beim Lernen mit [freeCodeCamp](https://www.freecodecamp.org/learn/). Vorgegebene Aufgaben und Beispielinhalte sind als Kurskontext zu verstehen. README-Dateien, die Aufteilung von TXT-Exporten, Browservorschauen und kleine technische Korrekturen wurden nachträglich mit KI-Unterstützung ergänzt. Die ursprünglichen Dateien bleiben außerhalb dieses Repositorys unverändert erhalten. Es wurde kein neuer Funktionsumfang als ursprüngliche Eigenleistung ausgegeben.

Die Sammlung enthält bewusst auch kleine Übungen. Nicht alle Beispiele sind für produktiven Einsatz oder vollständig barrierefrei ausgelegt. Externe Medien und vorgegebene Texte bleiben ihren Quellen zugeordnet. Eine pauschale Lizenz für fremde Inhalte wird nicht vergeben.
