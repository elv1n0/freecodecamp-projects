# Leap Year

Lernprojekt im Rahmen von freeCodeCamp.

## Inhalt

JavaScript-Grundlagenübung. Die ursprüngliche Logik liegt in `script.js`; die ergänzte Startseite zeigt Konsolenausgaben im Browser. Funktionen lassen sich zusätzlich über die Entwicklerkonsole ausprobieren.

## Starten

Öffne `index.html` in einem aktuellen Browser. Es ist kein Build-Schritt erforderlich.

## Herkunft und Aufbereitung

Ursprüngliche Datei: `freeCodeCamp-Curriculum/JavaScript/leapYear.js`.

Die ursprüngliche Lösung wurde für die Ablage auf GitHub strukturiert. README und gegebenenfalls Demo-Hülle sowie kleine technische Korrekturen wurden mit KI-Unterstützung ergänzt. Die Aufbereitung ist keine neue, unabhängig entwickelte Anwendung.

## Grenzen

Lern- und Demonstrationsprojekt. Keine produktive Anwendung. Externe Bilder, Videos und Schriftarten benötigen Internetzugang; deren Verfügbarkeit wurde nicht geprüft.
